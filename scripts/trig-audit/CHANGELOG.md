## Verification of the four equations

Each equation was checked in exact rational arithmetic in `reference/tests/test_rational_trig.py` and checked live (R1–R6) in `rational_trig.js`. Each live check has a control that must fail.

| Eq. | Statement | Verdict |
| --- | --- | --- |
| 85 | cos θ = (1 − Q)/(1 + Q), sin²θ = 4Q/(1 + Q)², tan²θ = 4Q/(1 − Q)², Q = tan²(θ/2) | **Verified exactly.** tan² has its pole at Q = 1 (θ = π/2). |
| 86 | Rot(u)x = x + 2/(1 + Q)(u × x + u × (u × x)) | **Verified exactly:** orthogonal, determinant 1, fixes u. The Cayley map (I − A)(I + A)⁻¹ of A = [u]× is Rot(−u), so the project's Cayley rotations were already this replacement. |
| 87 | x_F = Q₃/(Q₂ + Q₃)·2C₀, x_E = Q₃/(Q₃ − Q₂)·2C₀, (0, 2C₀; x_E, x_F) = −1 | **Verified exactly.** BF : FC = Q₃ : Q₂. x_E needs Q₂ ≠ Q₃; for an isosceles triangle the Apollonius point is at infinity. |
| 88a | Q_h(p, r) = ((1+\|p\|²)(1+\|r\|²) − 4p·r)² / ((1−\|p\|²)(1−\|r\|²))² − 1 | **Verified exactly:** Q_h = sinh² d. The 0.7 Claude fence already decides with this quantity, as w = (b² − σ)/σ. |
| 88b | ε_net = ε₁ + ε₂ + ε₃ + ε₁×ε₂ + ε₁×ε₃ + ε₂×ε₃ | **Qualified.** See below. |

The qualification of 88b:
- **Order.** The sum is correct to second order only, and only for tangent-half-angle (Gibbs) vectors composed as R(ε₁)R(ε₂)R(ε₃), with ε₃ acting first. When the drifts shrink tenfold its error shrinks about 1000×, which is third order. Taken in the reversed order R(ε₃)R(ε₂)R(ε₁), the error shrinks only about 100×, which is second order.
- **Rotation vectors.** If the ε are rotation vectors (angle × axis) rather than Gibbs vectors, the cross-term coefficient is ½, not 1.
- **The exact replacement** needs no truncation: R(a)R(b) = R((a + b + a×b)/(1 − a·b)). The PolyStep 3D coupler already composes exact quaternions, so the truncation never arose there.

## Verified in place, not changed

- **The four calculator engines** (both Galactic Lensing parts, Tri-Engine Convergence, Zero-Point Tri-Engine).
  - `exactLeg` converts each measured rotation once into the rational Gibbs vector u = v/(1 + w), then applies the exact Cayley map: eq. 86 in quaternion form.
  - The terminals' `sin` and `cos` return floats marked approximate.
  - Neither needs a change.
- **Hyperbolic PolyStep.**
  - Step lengths become the rational t = tanh(r/2) once, then cosh r = (1 + t²)/(1 − t²) and sinh r = 2t/(1 − t²). This is eq. 85 in hyperbolic form.
  - Frames are carried by the rational transvection.
  - The coupler composes exact quaternions.
- **The 0.7 Claude fence.** Every verdict is a comparison of the exact w = sinh² d (eq. 88a), or a certified sign.

## Deliberately not changed

- **The float search track** (H.dist, expOrigin, logOrigin, the horizon test `acosh(x₀) > R`, version 1's B3 frames). Its bits are fixed by the reference traces and by 7,740 preregistered runs.
  - A candidate for a later, re-registered round: the horizon test as x₀ > cosh R, which needs no `acosh` per point.
- **Intrinsically transcendental calls:** softmax and Sinkhorn transport weights, random normals, the cosine schedule, and the fence's portable exp/log kernels. These have no rational form, and none is wanted.
- **Drawing and readouts:** about 490 calls. Screen coordinates never feed back into the exact arithmetic.
