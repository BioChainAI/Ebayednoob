      Discrepancies in the file (flagged, not fixed)

      • Rotation axes. The code rotates tiers with rotAxis 'Z' (no base rotation: T0, T2, T4) and 'X' (base euler.x = π/2: T1, T3). The papers describe the alternation as X/Y.
      • Inferred 4th vertex. pInferred = pNode + qScale·((pUpper − pNode) + (pLower − pNode)) with qScale = 0.65 + 0.45·√A_R/(ΣQ + 1e-6 + 1). It equals the parallelogram closure only when qScale = 1, so it is not an exact closure (Panel A shows both points and their distance).
      • Tier frequencies. freq = 6W (96, 84, 72, 60, 48 Hz) appears in TIERS_SPEC but not in the papers.
      • Upper/lower phase offset. The 0.22 is applied to θ inside the winding term: φ_up = W_up·(θ + 0.22)·c2 + c3 + 2π/3, φ_low = W_low·(θ − 0.22)·c2 + c3 + 4π/3. The effective poloidal shift is ±0.22·W rad (about ±2.2 rad on T3), not 0.22 rad.
      • Small code details. A_R is clamped with Math.max(0, …); PHI is defined but no function uses it; the inspector labels [60:56] "mod-30 wheel and structure selector" but only [60:58] is decoded (the wheel index).

      Where this page departs from the file, and why

      1. Stage index. The page derives the stage as ⌊(pulseCount mod 150)/30⌋. The file advances a stage on the edge activeNode === 29 && previousActiveNode !== 29, which can be skipped when more than one pulse elapses in a frame. Deriving every quantity from the counter keeps all three panels on the same pulse at any speed or scrub position.
      2. Clock mode. Only the free-running clock is modelled (simSpeedBase = 1.0 times the speed slider, default 0.10x as in the file). The calculator's 6.0x/2.5x calculation speeds, keypad, rational evaluator and result latch are not part of this page.
      3. Scrubber. One lap is 150 pulses, and holonomic frames are 720·p/150 = 4.8 p. The file's own display uses (p + 1)/150 progress, i.e. it counts the current pulse as completed.
      4. Helix thickness. Tubes use radius 0.9 instead of 0.4 so they stay visible in a one-third-width panel. The curves (φ = Wθ·chiral + phase, 200 samples, closed Catmull-Rom, 150 segments) are unchanged.
      5. Scene contents. Not drawn: particle fields, radial lines, checkpoint diamonds, the trace orb and trail, the degree plane, the polar grid, and the idle group rotation. Added: 30 node markers on the active tier (coloured by syzygy) and the closure point V4*. TQF is shown for the active node only, and its geometry is updated in place instead of rebuilt each frame.
      6. Gear canvas. Copied unchanged; it is redrawn on every pulse of the shared clock rather than only while the CLUTCH tab is open.
      7. Engram. Hash and decoding copied; the 8×8 grid, bit toggling and Form selector are omitted (Form 1, the file's default, is applied).
      8. Additions with no source in the file. Panels B and C, the hover links, the correspondence table and the verification suite.
