                            Width w_e = O(n) → r = Θ(√log n)

                        1. 3-COLORING ($q=3$) REDUCTION THEORY
                        [Corollary 1.3 + Potts Tensor]
                    

                    

                        From $3v$-Variable 3-CNF to $2v$-Wire $C_3$ Chiral Tensor Contraction
                    

                    

                        In Corollary 1.3 of `paper.pdf`, proper 3-coloring on $G=(V,E)$ is encoded using $3v$ Boolean variables $x_{u,c}$ ($c\in\{1,2,3\}$) and $4v+3e$ clauses of width $\le 3$. While this proves $2^{o(v)}$ time, tripling the variable count ($n = 3v$) cubically inflates the subexponential base for moderate $v$. Our benchmark reduction compresses this in three steps:
                    

                    

                        $$\text{1. } S_3 \text{ Symmetry Pinning: Fix } c(v_1)=1, c(v_2)=2 \text{ on an edge } \implies \#\text{3-Col}(G) = 6 \cdot \#\text{3-Col}_{\text{pinned}}(G)$$
                        $$\text{2. 2-Bit } C_3 \text{ Chiral Encoding: } (b_{u,0}, b_{u,1}) \in \{00, 01, 10\} \text{ with } \neg b_{u,0}\vee\neg b_{u,1} \implies n = 2(v-2)$$
                        $$\text{3. Direct Bipartite Tensor Network (Thm D.1): } Z = \sum_{b \in \{00,01,10\}^V} \prod_{\{u,w\}\in E} \mathbf{1}_{\{b_u \neq b_w\}}$$
                    

                    

                        At the canonical 3-Coloring phase transition ($c = 2e/v \approx 4.69$, so $e \approx 2.345 v$ has bounded average degree), the bipartite tensor network of **Theorem D.1** has $s = O(v)$ wires and maximum degree $O(1)$, bypassing both the Appendix A sparsification tree and the Section 6 Beigel-Tarui parity lift to run in **$v^{O(1)} 2^{O(v/\sqrt{\log v})}$** time!
                    

                


                
                

                    

                        2. UNRESTRICTED CNF-SAT ($k = \omega(1)$ UP TO $n$)
                        [Overcoming the 3^k & 2^k Barriers]
                    

                    

                        Bypassing Tseitin Blowup & $2^{w_e}$ Monomial Expansion via Rank-1 Group Factoring
                    

                    

                        When clause width $w_e = |C_e|$ is unbounded (up to $n$), naive Tseitin splitting adds $O(m n)$ auxiliary variables, and Section 6's $\mathbb{F}_2$ expansion $v_e(x) = \prod_{j=1}^{w_e}(x_{i_j}\oplus b_j)$ explodes into $2^{w_e}$ monomials. We eliminate both bottlenecks via three exact reductions:
                    

                    

                        $$\text{1. Factored Port Evaluation (Thm D.1): } \Phi_e(Y|_{\delta(e)}) = 1 - \prod_{j=1}^{w_e}(1 - Y_{e,j}) \text{ takes } O(w_e) \text{ time (not } 2^{w_e}\text{!)}$$
                        $$\text{2. Rank-1 Group Factorization: } v_e(x) = \prod_{g=1}^r \underbrace{\prod_{l \in C_e \cap S_{t,g}} (1 - l(x_g))}_{u_{e,g}(x_g) \in \{0,1\}} \implies \text{effective width } w_e \to r = \Theta(\sqrt{\log n})$$
